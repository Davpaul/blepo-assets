# Chapmans circle element rules

1. Three circle elements at most on any one design.
2. Never put a magenta or purple element near the Chapmans logo (the logo is magenta). Near the logo use orange, white or navy tones.
3. No two elements share a colour. One element is dark navy tone, used as texture.
4. No two elements share a pattern. Patterns: fingerprint, concentric rings with a hole, solid circle, three rings (outer thickest).
5. One large anchor, one medium, one small. Let them run off the edges.
6. Keep text and pills clear. Supporting elements sit quieter than the anchor.
